# ArkZ ARModelViewer 1.0.0

Primeiro *release* público do **ArkZ ARModelViewer** — visualizador de modelos 3D
em **Realidade Aumentada** para Android, com o modelo ancorado em **marcadores de
imagem (QR code)** detectados pelo **ARCore (Augmented Images)**.

## Download (APK pronto)

**`ArkZ-ARModelViewer-1.0.0.apk`** — 45,8 MB (43,6 MiB) — disponível em *Assets*, no
fim desta página.

1. Baixe o APK e abra o arquivo no aparelho.
2. Autorize a instalação de **fontes desconhecidas** para o app que abrir o arquivo
   (navegador ou gerenciador de arquivos).
3. Instale, abra e conceda a permissão de **câmera**; aponte para um marcador
   impresso — as folhas prontas estão em `tools/print/`.

Requisitos: **Android 7.0 (API 24) ou superior**, com **ARCore** (Google Play
Services for AR).

## Destaques

* **Modelo ancorado no marcador** — renderização com
  [SceneView](https://github.com/sceneview/sceneview) 4.38.0 (Filament) sobre o
  rastreamento de imagem do ARCore 1.54.0.
* **Formatos**: `.glb`, `.gltf`, `.obj`, `.ply`, `.stl` e `.3mf`, com detecção
  pelo conteúdo do arquivo (não só pela extensão).
* **Ajuste fino no lugar**: painel com **rotação X/Y/Z** (inclinar/girar/rolar),
  **tamanho (maior dimensão)** e **elevação Z (plano do marcador)** — com efeito
  imediato, sem sair da cena de RA.
* **Marcadores**: dois embutidos (A e B), marcadores personalizados (imagem do
  aparelho) e um **gerador de marcador pseudo-QR** dentro do app; o app também
  exporta a **folha de impressão** do marcador em escala 100%.
* **Captura de tela** em três qualidades (Padrão 1280 px / Alta 1920 px / Máxima),
  salva na galeria **sem** a interface.
* **8 idiomas** (pt-BR, pt-PT, en, es, fr, it, de, zh-CN) com troca de idioma
  dentro do app.
* Escala automática pela largura do marcador, gestos de câmera (orbitar, zoom,
  pinça), ajuda na primeira execução e diagnóstico copiável para suporte.

## Instalação (compilando do código-fonte)

```bash
git clone https://github.com/em-rezende/Android-ArkZ-ARModelViewer.git
cd Android-ArkZ-ARModelViewer
```

```bash
# Windows
gradlew.bat :app:assembleDebug

# macOS / Linux
./gradlew :app:assembleDebug
```

Instale o APK gerado em `app/build/outputs/apk/debug/` (`adb install` ou copiando
para o aparelho). Requisitos de compilação: Android Studio atual, JDK 21+ e
Android SDK 37 (`platforms;android-37.0` + `build-tools;37.0.0`). Aparelho final:
**Android 7.0 (API 24) ou superior, com ARCore**.
